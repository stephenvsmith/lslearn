# lslearn: Local Structure Learning for Causal DAGs

In learning the structure of a causal DAG, users frequently want to
focus on select target nodes to focus their efforts. The algorithms
implemented in this package facilitate structure learning and edge
orientation based on the local neighborhoods of select target nodes, as
well as coordinate the information between the set of neighborhoods.
